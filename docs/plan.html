은혜 갚는 호랑이(가제)

밥약 끝나고 올리는 감사 스토리에 링크를 하나 붙입니다. 누르면 사준 선배를 신문 1면, 영수증, 상장으로 치켜세우는 1분짜리 병맛 헌정관이 열려요. 선배가 폰으로 끝까지 넘기면서 세 번 웃고, 캡처해서 자기 스토리에 다시 올리게 만드는 게 목표입니다.

무엇
스토리 링크 스티커로 여는 선배 헌정 페이지. 6장면을 탭으로 넘깁니다.
누가 보나
사준 선배가 폰(인스타 인앱 브라우저)으로 먼저 열고, 내 스토리를 본 친구들도 누릅니다.
잘 됐다는 신호
선배가 끝까지 넘기고, 캡처해서 리그램하거나 "ㅋㅋ 이거 뭐야" DM이 옵니다.

리서치에서 건진 것

고대 밥약은 이렇게 돌아간다

  • '밥'과 '약속'의 줄임말. 고려대 경영대 학생홍보대사는 "새내기가 입학하면 밥약이라는 걸 한다"고 소개하면서, 고연전 뒤풀이 때 선배들이 안암 일대 음식점을 후원해 준 일도 함께 꼽았습니다.아시아타임즈 2018
  • 고대생 칼럼에 따르면 3월엔 새내기가 밥 걱정할 필요가 없을 만큼 밥약이 활발합니다. 메뉴는 후배가 먼저 고르면 센스 있고, 후식은 후배가 눈치껏 삽니다.오르비 칼럼
  • 답례는 '보은'. 보통 "2밥약에 1보은"이고, 한 번 얻어먹은 선배에게는 안 해도 된다고 합니다. 대학내일 밥약 가이드는 식사 후 커피라도 사라고 권합니다.대학내일 2026

적용보은권(2밥약 1보은), 메뉴 고르기, 참살이길·안암 같은 지명, 호랑이가 전부 그대로 재료가 됩니다.

선배에게 밥약은 '돈 쓰는 일'이다

  • 잡코리아·알바몬 설문에서 대학생 81.9%가 밥약을 후회한 적이 있다고 답했습니다. 밥약 꼴불견 1위는 '밥만 얻어먹고 인사도 없는 먹튀 후배'(33.5%), 6위는 '사줬더니 시큰둥하게 먹는 태도'(7.1%), 8위는 '다른 선배가 사준 메뉴와 비교'(3.7%).디지틀조선
  • KBS 취재에서 한 2학년 선배는 "한 끼 먹을 때마다 2~3만 원씩 쓰면 용돈 받은 게 순식간에 없어진다"고 했습니다.KBS 2025.7

적용이 페이지가 선배에게 돌려줄 것은 '사준 보람'입니다. 먹튀가 아니라는 공개 인증이고, 맛있게 먹었다는 증거예요. 다른 선배와 비교하는 드립은 쓰지 않습니다.

감사 스토리와 주접의 문법

  • 대학내일 가이드가 "SNS 스토리에 선배를 태그해서 감사하다고 올려보라"고 권할 만큼, 감사 스토리는 이제 밥약의 정석입니다.대학내일
  • 커뮤니티 글을 보면 기본형은 음식 사진, 선배 태그, "밥약 감사합니다🫶" 한 줄 정도입니다.인스티즈
  • 주접은 과장과 말장난. 가수 김재환의 포스트 담당자가 쓴 "레늄(Re), 알루미늄(Al)으로 만들어진 게 분명해. 왜냐고? 진짜(Real)니까" 같은 원소 말장난이 대표적입니다.캐릿 2022

적용스토리 본문은 지금처럼 한 줄로 두고, 링크 스티커가 '더보기' 역할을 합니다. 주접 강도는 선배와의 거리에 맞춰 3단계 중에서 고릅니다.

기획

만들 때 지킬 것

  • 3초 안에 첫 웃음.로딩 화면이나 설명 없이 첫 장면부터 개그로 시작합니다.
  • 한 장면은 한 화면, 캡처 한 장.스크롤 없이 폰 한 화면에 끝나야 선배가 캡처해서 리그램하기 좋습니다.
  • 익숙한 서식을 비튼다.신문, 영수증, 상장, 쿠폰. 다들 아는 형식이라 설명이 필요 없습니다.
  • 만드는 데 폰으로 1분.밥 먹고 바로 스토리를 올리니까 입력은 이름, 메뉴, 장소, 한마디 정도면 충분합니다.
  • 밤티는 일부러, 쓰기 편한 건 제대로.워드아트와 방문자 카운터는 촌스럽게, 글자 크기와 버튼 누르는 영역은 제대로 만듭니다.
  • 스토리처럼 탭으로 넘긴다.스토리에서 들어왔으니 화면 오른쪽을 누르면 다음 장면. 버튼을 눌러야 하는 장면이 있어서 자동으로 넘어가지는 않습니다.

만드는 법

1단계 MVP주말 1~2일

  • 폰에서 쓰는 만들기 화면 → 링크 생성 → 복사
  • 6장면 헌정관. 탭으로 넘기고, 데스크톱에서도 안 깨지게
  • 내용은 링크 안에 담음. 서버와 DB가 없어서 비용 0원
  • 사진 대신 메뉴에 맞는 이모지 (마라탕이면 🌶️)
  • Vercel 무료 배포, 카톡 공유용 미리보기 이미지 1장

2단계반응이 좋으면

  • 짧은 링크(/h/abc123)와 음식 사진 업로드. DB와 파일 저장소 필요 (Supabase 정도)
  • 진짜 방문자 카운터, 선배 친구들이 남기는 "저도 사주세요" 방명록
  • 다른 고대생도 쓰는 '나도 만들기' 버튼. 스토리를 본 사람이 다음 사용자가 됨
  • 선배 답장 한 줄 ("다음엔 국밥이다")

안 할 것: 로그인, 결제, 학교 공식 로고, 자동 재생되는 소리.

기술과 데이터 형식

Next.js(App Router)와 TypeScript로 만들고 Vercel에 배포하는 걸 추천합니다. 1단계 화면은 만들기(/new)와 헌정관(/h) 두 개뿐이고, 2단계에서 DB를 붙여도 구조를 갈아엎지 않아도 됩니다. 헌정관 하나의 내용은 아래 형식으로 정해 두고, 1단계에선 이걸 그대로 링크(/h?d=…)에 담습니다. 링크는 300자 안팎이고, 스티커 문구로 가려지니 길이는 문제없습니다.

type Tribute = {
  v: 1;              // 링크 형식 버전
  senior: string;    // 선배 이름 ("선배님"은 화면에서 붙임)
  major?: string;    // 학과
  year?: string;     // 학번 두 자리
  junior: string;    // 내 이름
  menu: string;      // 먹은 메뉴
  price?: number;    // 없으면 영수증에 '비공개'
  place?: string;    // 장소
  date: string;      // YYYY-MM-DD
  note?: string;     // 한마디, 속보 인터뷰로 들어감
  level: 1 | 2 | 3;  // 주접 레벨
};

확인할 것

  • 아이폰과 안드로이드의 인스타 인앱 브라우저, 카톡 인앱 브라우저에서 직접 열어 보기
  • '아니요' 도망: 마우스는 올리기만 해도, 터치는 누르는 순간 이동하는지
  • 한글 웹폰트가 늦게 와도 레이아웃이 안 무너지는지, 첫 화면이 2초 안에 뜨는지
  • 긴 이름·긴 메뉴("엽기떡볶이 오리지널 착한맛 + 주먹밥")에서 줄바꿈
  • 조사 자동 처리 (마라탕을 / 꿔바로우를, 새내가 / 민준이가). 시안에는 이미 넣어 둠
  • 링크 스티커 문구 변경과 눌렀을 때 바로 열리는지

선 넘지 않기

  • 실명, 학과, 학번 조합은 내 스토리를 보는 모두에게 공개됩니다. 선배에게 미리 물어보거나 이름만, 아니면 '김OO'로 씁니다.
  • 금액은 기본 비공개. 공개하면 선배가 허세나 짠돌이처럼 보일 수 있고, 다른 후배들에게 기준이 생깁니다.
  • 다른 선배와 비교하는 드립은 금지 (밥약 꼴불견 8위). 외모·연애 드립도 빼는 게 안전합니다.
  • 학교 공식 로고와 교표는 쓰지 않습니다. 크림슨 색과 호랑이 분위기 정도만.
  • 가짜 신문은 이름부터 패러디(밥약일보)로. 실제 언론사 이름이나 로고는 쓰지 않습니다.

정할 것

  1. 나만 쓸까, 다른 고대생에게도 열까? 열면 2단계(짧은 링크, DB)가 필요합니다.
  2. 음식 사진을 넣을까? 넣으면 2단계부터, 빼면 1단계로 바로 만들 수 있습니다.
  3. 이름. 은혜 갚는 호랑이(가제), 밥약일보, 선배님 헌정관 중에서.
  4. 6장면 중 빼거나 바꿀 장면. 상장을 빼고 '선배 능력치 카드'를 넣는 식의 교체도 가능합니다.
