밤티 레시피

허접하게, 근데 정성껏

기존 시안(6장면을 탭으로 넘기는 선배 헌정관)을 바탕으로, 사람들이 좋아하는 병맛·밤티 감성이 어떻게 만들어지는지 더 찾아봤습니다. 특히 요즘 바이브코딩으로 쉽게 만드는 3D와 직접 조작하는 게임 쪽을 중심으로 봤어요.

결론 먼저

  1. 밤티는 원래 '못생기고 촌스럽다'는 놀림말입니다. 반대말은 2026년 9월부터 '장원영'이에요. 그래서 밤티는 사이트 디자인과 나(후배)가 맡고, 선배님은 언제나 장원영 쪽에 둡니다. 선배 외모를 밤티로 만드는 순간 그냥 놀림이 됩니다.
  2. 사랑받는 B급은 '잘 만든 의외성'입니다. 촌스러움은 서체·장식·손그림에만 쓰고, 메뉴·날짜·사진·버튼 반응은 정확해야 일부러 그런 걸로 읽혀요.
  3. 정성은 보여야 효과가 납니다. 오래 걸렸다는 걸 알면 같은 결과물도 더 높이 평가한다는 연구가 있어요. 엔딩 크레딧처럼 제작 기간과 도구를 대놓고 보여 주세요.
  4. 조작형은 '3초 안에 시작, 조작 하나, 30초 안에 끝, 결과는 캡처 한 장'입니다. 퍼진 웹 장난감과 물리 코미디 게임에서 공통으로 보이는 문법이에요. 그리고 결말은 뭘 해도 선배가 이기게 짭니다.
  5. 3D는 '한 장면, 한 조작'까지만 하세요. 인스타 인앱 브라우저에서는 기울이기·마이크 같은 기기 기능이 불안정해서, 탭·드래그로만 끝까지 갈 수 있어야 합니다.

'밤티'는 무슨 뜻이고, 어디에 써야 하나

경기일보(2026.5.2)는 밤티를 "못생겼거나 별로라는 뜻으로 외모·스타일이 촌스럽거나 어색할 때 놀리는 맥락에서" 쓰는 말이라고 설명합니다. 아바타 게임 '라인플레이'에서 닉네임이 밤티인 사용자의 아바타가 외모 지적을 받은 장면이 캡처돼 퍼지면서 밈이 됐어요.

2026년 9월에는 반대말로 '장원영'이 붙었습니다. 너무 좋은 것에 '장원영 신발', '장원영 당면'처럼 이름을 붙이는 식이에요. 장원영 본인도 팬 플랫폼에서 이렇게 반응했습니다.

"다들 밤티 같은 밥 먹지 말고 장원영 밥 먹고, 밤티 같은 하루 대신 장원영 하루 보내"엘르 코리아, 2026.9.11

"B급은 저예산이 아니라 잘 만든 의외성"이고, 의도가 안 보이는 연출은 성의 없어 보인다는 분석입니다. 배민의 고구려 수렵도 패러디, 충주시 유튜브처럼 정색한 형식에 하찮은 내용을 담는 게 공통점이에요. 충주시 김선태 주무관은 "'우리 이렇게 밖에 못해'… 거기에 한 스푼의 센스"라고 했습니다.

Pratfall effect

기술 현실

인스타·카톡 인앱 브라우저에서 되는 것

선배는 거의 무조건 인스타 스토리 링크로 엽니다. 그래서 일반 사파리·크롬이 아니라 인앱 브라우저 기준으로 봤어요. '기기 확인'은 자료로 확정하지 못해서 실제 폰으로 열어 봐야 하는 항목입니다.

기능인앱에서이렇게 쓰기
탭 · 드래그됩니다.기본 조작으로. 게임 영역엔 touch-action:none, overscroll-behavior:none을 주고, 인앱의 뒤로가기 제스처와 부딪히지 않는지 기기 확인.
3D (WebGL)됩니다. 다만 아이폰은 메모리 한도를 넘으면 경고 없이 페이지가 새로고침된다는 보고가 2026년 3월에도 미해결입니다.3D 장면은 한 번에 하나, 텍스처 1024px 이하, 그림자 끄기, 화면 배율 1.5 이하, 장면을 나갈 때 리소스 정리.
기울이기 · 흔들기조건부. 아이폰은 탭 안에서 권한을 요청하면 팝업이 뜨는 게 기본이지만 앱이 막을 수 있어요. 안드로이드는 기기 확인."시작" 버튼에서 권한 요청. 거부되거나 안 되면 드래그로 자동 전환.
마이크 (불기)가장 불안정. 안드로이드 카톡 인앱에서 허용해도 에러가 난다는 2026년 8월 보고가 있습니다.보너스로만. 기본 조작은 '꾹 누르기'.
진동아이폰은 전 버전 미지원.화면 흔들림과 효과음으로 대신.
소리첫 탭 이후에만 납니다. 아이폰 무음 스위치가 켜져 있으면 안 날 수 있어요.소리 없이도 웃기게 만들고, 소리는 덤.
결과 이미지 저장화면에서 만든 이미지를 바로 다운로드시키는 방식은 인스타·카톡 모두 거의 실패합니다. 카카오 공식 답변으로는 둘 다 되는 건 서버 응답 헤더 방식뿐.서버가 PNG를 만들어 다운로드 헤더로 내려주기, 또는 이미지를 띄우고 "꾹 눌러 저장" 안내.
스토리로 바로 공유웹에서는 불가. Meta의 공식 방식은 앱 전용입니다."캡처해서 올려 주세요"가 제일 확실해요. 그래서 결과 화면을 캡처 한 장에 맞추는 게 저장 기능보다 중요합니다.

도구 고르기

다른 세션은 지금 Hono 서버, esbuild, TypeScript로 화면을 서버에서 그리는 구조로 만들고 있어요(React 없음). 이 구조에 맞춰 골랐습니다. 크기는 압축(gzip) 기준입니다.

도구크기언제
CSS 3D transform0KB가챠 카드 뒤집기, 상장 회전, 동상 흉내. 라이브러리 없이 되고 바이브코딩도 제일 쉬워요. 3D 느낌의 80%는 이걸로 충분합니다.
three.js약 186KB진짜 3D 한 장면(동상 제막식). esbuild의 동적 import로 그 장면에서만 받고, 바로 앞 장면에서 미리 받아 둡니다.
model-viewerthree 포함 약 260KBGLB 모델 하나 돌려 보기. 웹 컴포넌트라 React 없이 태그 하나로 됩니다. 인스타 인앱에서 AR 기능은 안 됨.
matter.js약 26KB2D 물리. 수박게임, 인형뽑기, 쟁반 나르기.
cannon-es약 34KB3D 물리가 꼭 필요할 때만.
피할 것Babylon.js(약 500KB), Rapier(1.65MB), Spline 임베드, React Three Fiber(React가 없는 지금 구조엔 안 맞음).

밤티 3D는 성능에도 유리

PS1 시절처럼 렌더 해상도를 0.3~0.5배로 낮추고 캔버스를 픽셀이 보이게 늘리면(image-rendering:pixelated) 그릴 픽셀이 1/4~1/10로 줄어요. 텍스처는 뭉개지지 않게 최근접 필터로, 저폴리 모델이면 메모리로 죽을 위험도 줄어듭니다.

적용 황금 메뉴 동상은 일부러 각진 저폴리 + 저해상도로.

AI로 3D 모델 만들 때

Meshy 무료는 월 100크레딧이고 무료 결과물은 출처 표기(CC BY)가 필요해요. Rodin의 저폴리 변환은 유료입니다. Hunyuan3D 오픈소스 라이선스는 한국을 적용 지역에서 뺐으니 쓰지 마세요. AI 원본은 수백만 면이 나올 수 있어서 gltf-transform으로 줄여야 합니다(목표: 모델당 2만 삼각형, 1MB 이하).

더 쉬운 길 3D 파일 대신 나노바나나식 '피규어 상자' 이미지 한 장.

성능 예산

  • 첫 화면은 3D 없이 2초 안에 뜨게 (구글 기준 2.5초 이하가 '좋음').
  • 첫 로딩 JS는 150KB 이하. 3D 묶음은 300KB 이하로 따로 떼서 필요한 장면에서만.
  • 음식 사진까지 합쳐 전체 3MB 이하. 사진은 서버에서 줄이고 WebP로.
  • 화면 높이는 100vh 대신 100dvh. 인앱 툴바 때문에 어긋나요.

참고로 Alex Russell의 2026년 분석은 중급 안드로이드 폰에서 3초 안에 열리려면 전체 2MiB, JS 0.3MiB가 한도라고 봅니다.

실제 폰으로 확인할 것

아이폰·안드로이드 × 인스타·카톡 네 조합에서, 가능하면 오래된 아이폰 한 대 포함.

  • 3D 장면을 다섯 번 들어갔다 나와도 페이지가 새로고침되지 않는지
  • 저전력 모드에서도 버벅이지 않는지 (아이폰 저전력 모드는 30fps 제한 보고)
  • 기울이기 권한 팝업이 뜨는지, 거부하면 드래그로 넘어가는지
  • 무음 스위치를 켠 상태에서 효과음
  • "꾹 눌러 저장"과 다운로드 버튼으로 사진 앱에 실제로 저장되는지
  • 드래그할 때 인앱 브라우저의 닫기·뒤로가기 제스처와 부딪히지 않는지
  • 인앱 툴바 때문에 화면 아래가 잘리지 않는지

테스트할 땐 인앱 브라우저 기능을 한 번에 점검해 주는 inapp-debugger를 같이 열어 보면 편해요.

조심할 것

  • 밤티는 외모 놀림말입니다. 선배 얼굴이나 옷차림에 밤티 연출을 쓰지 않습니다. 하찮은 손그림 선배를 넣는다면 외모 특징은 과장하지 말고 졸라맨 수준으로.
  • "또 사주세요"는 압박으로 읽힐 수 있어요. 선배 81.9%가 밥약을 후회한 적이 있다는 설문이 있습니다(기존 조사). 주접의 방향은 '더 사 주세요'가 아니라 '갚겠습니다'.
  • 유행 밈에 올라탄 콘텐츠가 비하·외모 묘사로 역풍을 맞은 사례가 계속 나옵니다. 피식대학 영양군 편(2024.5, 지역 비하 논란 후 구독자 약 30만 명 감소), 제주청년센터 홍보 영상(2026.3, 외모 묘사로 삭제·사과), 경남교육청 골반춤 밈 영상(2025.10, 삭제·사과).
  • AI로 선배 얼굴을 피규어·3D로 만드는 건 본인 허락이 있을 때만. 허락이 없으면 메뉴나 호랑이를 주인공으로 둡니다.
  • 밈 문장은 장면당 하나. 몇 달 지나면 낡아 보이니 바꾸기 쉬운 곳(문구 데이터)에 둡니다.
